~ FEATURES

what it does

Mock Interview Sessions

Practice interview questions with your own CV as context. Streaming Q&A, session history, copy answers, and three answer-length presets.

Coding Assistant

Language detection for 6 languages (Python, C++, Java, JavaScript, C, Go) with 5-section solutions, syntax-highlighted editor, and Copy/Regenerate/Explain controls.

CV Import & Context

Import PDF/DOCX/TXT resumes with parsing and extraction. Truthful context engine with anti-fabrication rules keeps answers grounded in your actual experience.

Voice Pipeline

Voice interface fully powered by cloud LLMs — real-time audio to transcription, question detection, and answer generation. No local models required.

Screen Analysis

One-click whole-screen capture reads questions from your screen and solves them — no region selection needed.

Privacy Mode

Manual toggle hides your CV, history, and API keys from screen capture. Capture exclusion removes the app window from shared screens entirely.
